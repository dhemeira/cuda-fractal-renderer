# Fractal Renderer

With this CUDA project you can generate beautiful fractals quickly with your GPU.

You can also run a comparison between your CPU and GPU to see how much faster the GPU version is.

There is also a PowerPoint presentation in hungarian that outlines the workings of the software with some runtime comparisons also included.
